# Privacy

TTD Form Assistant stores booking profiles only in encrypted form in `chrome.storage.local` on the current Chrome profile.

Stored profile data may include pilgrim names, ages, genders, Photo ID Proof types, Photo ID Numbers, email, city, state, country, and pincode. These are sensitive personal details.

- Encryption: AES-256-GCM
- Key derivation: PBKDF2-SHA-256
- Passphrase storage: never stored
- Network transmission: none
- Analytics or tracking: none
- Third-party sharing: none

Use the extension only on a trusted personal computer. Remove it and its local data when it is no longer needed.
